CONTEXTE

Le projet à auditer est Jarod-OS, anciennement Herald OS, avec son noyau
Jarod dérivé de Hermes.

Jarod-OS doit devenir l’interface centrale du PC :
- agent local/cloud ;
- contrôle sécurisé de Windows ;
- mémoire et RAG ;
- sous-agents ;
- voix et vision locales ;
- automatisations ;
- installation et lancement d’applications locales ;
- intégration de services externes ;
- extension progressive sans casser les contrats existants.

Le projet possède notamment :
- un shell Electron/React ;
- un noyau Jarod/Hermes ;
- une passerelle JSON-RPC/WebSocket ;
- un bridge d’outils système ;
- une politique executeGuardedTool ;
- des permissions et un journal audit.jsonl ;
- un sélecteur de modèles locaux ;
- un portage Windows natif sans WSL.
